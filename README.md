# 🧾 KaikeiPOS — 会員登録つき かんたんレジ

スマホ・タブレットで使えるレジアプリ（PWA）。**アカウントを作ってログインすると、自分の商品と売上だけが見られます。**

```
アカウント作成 / ログイン
      ↓
  ダッシュボード
      ├─ 商品登録   … 商品名・金額（必須）＋原価（任意）
      ├─ レジ       … 商品をタップ → 合計点数 / 合計金額 → お預かり → おつり → 会計
      └─ 販売レポート … 年 / 月 / 日別の売上・原価・粗利・商品別・会計履歴
```

- 📱 iPhone / Android / タブレット対応（ホーム画面に追加できます）
- 🔐 ログイン必須。データは Supabase の RLS で**本人以外は読めません**
- 🌐 GitHub Pages に置くだけで動く静的サイト（サーバー管理不要）
- 💸 Supabase の無料枠で運用できます

## セットアップ（初回だけ・15分ほど）

### 1. Supabase で無料プロジェクトを作る

1. <https://supabase.com> でサインアップ → **New project**
2. Name は何でもOK。**Region は `Northeast Asia (Tokyo)`** が速くておすすめ
3. Database Password は控えておく（このアプリでは使いませんが再設定時に必要）

### 2. テーブルを作る

1. 左メニュー **SQL Editor** → **New query**
2. このリポジトリの [`supabase/schema.sql`](supabase/schema.sql) の中身を全部貼り付け → **Run**
3. `Success. No rows returned` と出れば完了（商品・会計・明細テーブルとRLSが作られます）

### 3. メール確認をオフにする（すぐ使いたい場合）

初期状態では新規登録時に確認メールが必要です。自分用のレジなら off が楽です。

1. 左メニュー **Authentication** → **Sign In / Providers** → **Email**
2. **Confirm email** を **OFF** → Save

> ON のままにする場合は、**Authentication → URL Configuration → Site URL** に
> 公開URL（例 `https://<ユーザー名>.github.io/pos-app/`）を入れてください。

### 4. 接続キーを貼る

1. **Project Settings → API** を開く
2. `Project URL` と `anon public` キーをコピー
3. [`js/config.js`](js/config.js) に貼り付けて保存

```js
export const SUPABASE_URL = "https://xxxxxxxxxxxx.supabase.co";
export const SUPABASE_ANON_KEY = "eyJhbGciOi....";
export const SHOP_NAME = "うちの店";   // ダッシュボードの表示名（任意）
```

> **anon キーは公開して大丈夫なキーです。** ブラウザに配る前提で設計されていて、
> `schema.sql` で有効化した RLS により「ログイン中の本人の行」しか読み書きできません。
> 逆に `service_role` キーは絶対に置かないでください。

### 5. ローカルで動作確認

ES モジュールを使っているので、`index.html` を直接ダブルクリックでは動きません。簡易サーバー経由で開きます。

```bash
cd pos-app
python -m http.server 8000       # または: npx serve .
# → http://localhost:8000 をブラウザで開く
```

### （おまけ）動作テスト

Supabase を模したモックで、ログイン〜商品登録〜レジ〜レポートの一連の流れを自動チェックできます。

```bash
npm install     # jsdom を入れる（初回だけ）
npm test        # 90項目のチェックが走ります
```

## GitHub Pages で公開する

```bash
cd pos-app
git init
git add .
git commit -m "KaikeiPOS: 初回コミット"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/pos-app.git
git push -u origin main
```

その後、GitHub のリポジトリで:

- **Settings → Pages → Source** を `Deploy from a branch`、Branch を `main` / `(root)` → Save
- 数分後 `https://<ユーザー名>.github.io/pos-app/` で公開されます

（`Source` を `GitHub Actions` にすると、同梱の `.github/workflows/deploy.yml` で自動デプロイされます）

**スマホでの使い方**: 公開URLを開く → ログイン → ブラウザメニューの「ホーム画面に追加」。
以降はアプリのように起動します。

## 画面の使い方

### 商品登録
- **商品名** と **金額** は必須。**原価**は任意（入れると販売レポートで粗利が出ます）
- 🗑 を押すとレジの一覧から外れます。**過去の売上データは消えません**（明細には販売時点の商品名・金額・原価が保存されています）

### レジ
1. 商品ボタンをタップ（同じ商品を続けてタップすると点数が増えます。カゴの `−` `＋` でも調整可）
2. **合計点数** と **合計金額** が自動表示
3. **お預かり** を入力 → **おつり**が表示（`ちょうど` / `1,000` / `5,000` / `10,000` のボタンあり）
   - 足りない場合は「◯◯不足」と赤字になり、会計ボタンは押せません
   - 未入力のまま会計した場合は「ちょうど受け取った（おつり0円）」として記録します
4. **会計する** → 日付・会計番号（例 `20260725-001`）・商品明細が販売レポートへ記録されます

### 販売レポート
- **年 / 月 / 日** を切り替えて集計
- 表示項目: 売上 / 原価 / 粗利（粗利率）/ 会計数 / 販売点数
- **月別・日別の内訳**は行をタップするとその期間へドリルダウン
- **商品別**（点数・売上・粗利）と**会計履歴**（日付・会計番号・商品名・金額）も確認できます
- 原価が未設定の商品は原価0として計算します（注意書きが出ます）

## 複数端末で同じアカウントを使う

スマホとタブレット、2台のレジ…といった同時利用に対応しています。

- **同時ログインOK** — 端末ごとに別のセッションを持ちます（1台で入り直しても他は落ちません）
- **ログアウトはその端末だけ** — 他の端末のログイン状態は維持されます（`scope: "local"`）
- **会計番号は重複しません** — DBの一意制約＋自動リトライで、同時に会計しても `…-001` / `…-002` と割り振られます
- **商品の追加・削除の反映** — 「商品登録」「レジ」の画面に入るたびに取り直します。レジを開いたまま別端末で商品を追加した場合は、いちど別画面に移って戻れば出てきます
- **レポート・本日の売上** — 表示のたびに集計するので、どの端末の会計もすぐ合算されます

注意点:

- 画面を開いたまま放置しても**自動では更新されません**（リアルタイム同期は未実装）。最新にしたい時は画面を入り直してください
- 集計日は**操作した端末のローカル日付**で記録します。各端末の日付・タイムゾーン設定は合わせておいてください
- 同じ商品を2台で同時に会計しても在庫の二重販売チェックはしません（在庫管理機能なし）

## データ構造

| テーブル | 内容 |
| --- | --- |
| `products` | 商品マスタ（商品名 / 金額 / 原価 / 表示フラグ） |
| `sales` | 会計1件（会計番号 / 日時 / 販売日 / 合計点数 / 合計金額 / 原価合計 / お預かり / おつり） |
| `sale_items` | 会計の明細（販売時点の商品名・金額・原価・点数） |

いずれも `user_id` を持ち、RLS で `user_id = auth.uid()` の行だけにアクセスできます。

## 無料枠について（2026年7月時点）

- Supabase Free: プロジェクト2つまで / DB 500MB / 月間アクティブユーザー 50,000人
  → 個人店のレジ用途なら十分すぎる容量です（1会計あたり数百バイト程度）
- ⚠️ **1週間まったくアクセスが無いと、無料プロジェクトは自動停止**されます（ダッシュボードから復帰可）。
  毎日使うなら問題ありません。

## 制限事項

- オフラインでは**画面は開けますが、会計の登録・レポート表示はできません**（DBが必要）。
  電波が不安な場所で使う場合は、この点だけ注意してください。
- 商品の**編集**は未実装です（作り直し＋🗑 で対応）。
- 消費税は「金額＝税込」前提の単純計算です。区分別の税計算はしていません。
